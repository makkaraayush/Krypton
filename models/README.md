# 3D Printing & Slicing Hub

This directory contains the complete 3D model suite, multi-color slicing configurations, and the Bambu Studio 3MF project for Krypton.

## Guides

- [filament_palette.md](filament_palette.md): 5-spool filament palette breakdown, assigned STLs, and calibrated AMS purge volumes.
- [plates_and_slicing.md](plates_and_slicing.md): 4-plate zero-waste print schedule, modifier geometries, and geometry notes on `topsurfaceUP6.stl`.

## Asset Folders

- `stl/fingers/`: Finger joint segments (`Index3.stl`, `Majeure3.stl`, `ringfinger3.stl`, `Auriculaire3.stl`, `thumb5.stl`).
- `stl/forearm/`: Forearm chassis spine (`robpart2V4.stl` through `robpart5V4.stl`, `robcap3V2.stl`).
- `stl/wrist/`: Wrist articulation bearings (`WristlargeV4.stl`, `WristsmallV4.stl`, `Bolt_entretoise7.stl`).
- `stl/armor/`: Outer cyberpunk shrouds (`coverfinger1.stl`, `topsurfaceUP6.stl`, and legacy archive `topsurface6.stl`).
- `stl/drive_mechanism/`: Servo winches, offset pulleys, and bracket mounts.
- `3mf/`: Production Bambu Studio project (`Krypton_Bambu_A1_AMS_Plates.3mf`).

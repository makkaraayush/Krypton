# Servo Drive Mechanism

Contains the servo mounting frame, winch pulleys, and electronics bracket:
- `RobServoBedV5.stl`: 5-slot mounting bed designed for TowerPro MG996R servos, securing them in a staggered layout along the forearm axis.
- `ServoPulleyHitecV5_tighter.stl`: High-torque tendon winch spools with tighter 25T spline engagement (print 5 copies).
- `Bottom_Offset_ServoPulleyHitecV5.stl`: Lower offset pulley spacer for alignment.
- `Top_Offset_Screw_Recess__ServoPulleyHitecV5.stl`: Top pulley cap with M3 screw recess.
- `ardiuinosupport.stl`: Electronics carrier bracket for ESP32 and PCA9685 boards.

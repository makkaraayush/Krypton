# Wrist Bearing & Rotation Components

Wrist articulation assembly, gear ring, and tendon routing:
- `WristlargeV4.stl`: Main wrist outer rotating ring / sleeve.
- `WristsmallV4.stl`: Inner wrist clamping collar and axle spacer.
- `cableholderwristV4.stl`: Central wrist cable guide plate maintaining tendon alignment through the wrist axis.
- `Bolt_entretoise7.stl`: Low-friction wrist tendon pass-through spacer sleeve.
- `WristGearsV4.stl`: Internal ring gear set for motorized or manual wrist pronation/supination.
- `rotawrist1V3.stl`: Rotating wrist chassis segment 1.
- `rotawrist2.stl`: Rotating wrist collar segment 2.
- `rotawrist3V2.stl`: Rotating wrist segment 3 / transition collar to hand palm.

# Wrist Bearing Components

Wrist rotation collars and tendon routing components:
- `WristlargeV4.stl`: Main wrist outer rotating ring / sleeve.
- `WristsmallV4.stl`: Inner wrist clamping collar and axle spacer.
- `cableholderwristV4.stl`: Central wrist cable guide plate maintaining tendon alignment through the wrist axis.
- `Bolt_entretoise7.stl`: Low-friction wrist tendon pass-through spacer sleeve.

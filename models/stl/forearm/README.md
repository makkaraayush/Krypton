# Forearm Structural Chassis

Forearm structural spine segments and end cap:
- `robpart1V2.stl`: Base forearm section connecting elbow and electronics tray to lower chassis.
- `robpart2V4.stl`: Lower forearm segment with cable routing channels.
- `robpart3V4.stl`: Mid-forearm segment.
- `robpart4V4.stl`: Upper forearm segment with servo bed mounting tabs.
- `robpart5V4.stl`: Distal forearm segment transitioning to the wrist collar.
- `robcap3V2.stl`: Structural end cap and retaining collar.
